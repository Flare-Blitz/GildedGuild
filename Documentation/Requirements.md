# Cut Features
This outlines everything we talked to Cody about having to cut from our initial pitch

## Game Expansions
We will not be implementing any of the game expansions that we said we would. We initially added it to help justify the existance of the project, however designing a ML model that can adapt to multiple combinations of expansions was too large of a scope of the project. Also, the code to add the expansions to Unity would have been an incredible amount of work, all for just extra stuff not essential to the core pitch.

## Game Analytics
This was a feature to justify the existance of the frontend and a database. We ended up getting behind on implementing the fronend and backend due to the immense work of the python training and Unity code, and elected it was better to cut the feature and focus more-so on the Machine Learning and gameplay.
